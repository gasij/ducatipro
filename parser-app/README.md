# Ducati Parser App

Отдельное локальное приложение для разбора таблиц товаров и совместимости.

## Запуск

```bash
cd parser-app
npm start
```

После запуска открой:

```text
http://localhost:4177
```

## Что умеет

- читать `.xlsx`, `.csv`, `.tsv`, `.json`;
- собирать товары по артикулу;
- подтягивать модели из файла совместимости;
- показывать предпросмотр первых 100 товаров;
- экспортировать результат в JSON или CSV;
- отправлять результат в Directus.

Для XLSX используется системная команда `unzip`, на macOS она обычно уже есть.
